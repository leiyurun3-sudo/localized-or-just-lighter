# SAM-Flow 跨种子实验

本次归档中，seed 1 已完成 42 个源图的 420 个输出。seed 2 在 12 个源图完成默认点与回放的 48 个输出。下表列出运行模式的设计规模。

上传整个 ZIP 到 AutoDL 的 `/root/autodl-tmp`，在 Jupyter 终端运行：

```bash
cd /root/autodl-tmp
unzip -oq A_SAM_SeedCheck.zip
bash A_SAM_SeedCheck/start.sh full 1,2
```

若只做默认工作点，把最后一行的 `full` 改为 `light`。只跑一个种子可将 `1,2` 改为 `1` 或 `2`。同一目录下从 light 切换到 full 会复用同种子、同环境已经完成的输出。中断后用原命令续跑。监控每 3 秒刷新，Ctrl+C 关闭监控；实验在后台继续。每个种子结束即在 `/root/autodl-tmp` 生成 `A_SAM_seed1_full.zip` 或 `A_SAM_seed2_full.zip`，轻量版文件名含 light。等状态显示 completed、对应 ZIP 打包完成后再关机。

**环境。** 程序读取上轮的本地模型 `/root/autodl-tmp/local-models/FLUX.1-dev`，路径不同时先设置 MODEL_PATH。生成脚本及配置来自 seed 0 归档，默认 BF16 和 model CPU offload。原环境是 RTX 4080 SUPER、torch 2.8.0+cu128 和 torchvision 0.23.0+cu128。如果是新镜像，先运行 `bash A_SAM_SeedCheck/prepare.sh`，它沿用镜像的 CUDA PyTorch，并在项目子目录安装归档依赖；有 AutoDL 加速脚本时自动启用。故障记录在 `A_SAM_SeedCheck/runs/batch.log`。

**实验范围。** 固定原来 42 张有背景像素的 PIE 源图、提示词、掩码口径和求解器。每个源的侦察和编辑使用配对的样本种子 1 或 2，SAM 内部参考噪声保持上游设定 999。每个种子重新生成侦察图、在自身的原生 Spatial 轨迹上拟合两分支常数并取得回放目标。每个种子先做原生/观测算子的数值一致性检查。

| 模式 | 每源每种子 | 每种子 | 两个种子 |
| --- | --- | ---: | ---: |
| light | 默认 Spatial、Uniform、每图两常数、目标为 Spatial 的 Uniform 回放 | 168 | 336 |
| full | 以上四个输出，加 0.25、0.50、0.75 下的 Spatial 和 Uniform | 420 | 840 |

四档主分析的第 4 档是默认 1.0。原五档中 1.25 的外推结果（含 5/41）仍属 seed 0。两个模式均沿用全体 42 张，选择依据只是原掩码有背景像素。此次只扩展 SAM；恢复算子、额外 FlowEdit 基线和全局共用常数不占用本轮任务。与种子相关的内部 scout 成本已计入预算。按归档中同 42 张源图分项计时，每种子默认四臂约 7.3 小时、侦察约 1.5 小时、完整扫描额外约 11.0 小时；模型加载、工程检查、打包及机器差异会影响实际用时。

**拿回结果。** 每个结果 ZIP 含可计算论文指标的原始 512×512 输出、投影轨迹和运行记录。在原 Windows 电脑解压实验包，把下载的**结果 ZIP** 拖到 `score_local.cmd` 上即可按原权重在 CPU 评分，也可运行 `score_local.cmd "结果.zip"`。每个 ZIP 旁会生成同名加 `_scores` 的目录。内含逐输出分数、默认指标和 95% 源级 bootstrap 区间。完整版另附逐源共同响应区间、差值及正响应敏感性。比较不同种子可运行：

```text
python study/compare_seeds.py <seed1评分目录>/scores.csv
```

该命令复算两个完整种子。seed 2 默认点的复算入口见[证据索引](../../reproduction/EVIDENCE_INDEX.md)。程序加入随包的 seed 0 基准，同时给出各自有共同区间的源图，以及各完整种子共有源图上的配对变化。百分比均用同一支持子集的均值之比；汇报真实分母和效应量。区间在每个种子内按源图重采样。
