当前为交给 BPaper 的参考实现，尚未 GPU 执行。论文保持原样，方法分支保持独立。

40 个新 PIE 源（排除 90 个历史源并做图像去重）× 2 seeds × 6 臂 = 480 输出。风格类剩余源没有官方保留区域，本轮限定 9 类有保留区域的编辑任务。源/提示/种子已保存在 manifest.json。

| 臂 | 校正方向 | 实际逐步幅度 |
|---|---|---|
| REQ | 正确请求图 P | 自身 .25 P c，记录 bR |
| GLB_R | 全局 c | 重放 bR |
| U25 | 全局 c | 自身 .25 c，记录 bU |
| REQ_U | 正确请求图 P | 重放 bU |
| SHUF_R | 同一源图、错误目标提示的响应图；秩匹配到正确 P 的直方图 | 重放 bR |
| REV_R | 1.25-P | 重放 bR |

真正编辑时六臂都用正确目标提示。记忆固定，不随错误图或反向图改变。幅度轨迹是因子，不预设 U25 每步都更大。主检验为 REQ_U−U25 的保护区 LPIPS；其余统计见 stats_plan.json。
