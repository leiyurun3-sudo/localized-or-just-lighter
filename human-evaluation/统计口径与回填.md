# 默认配置人工盲评：统计口径与回填

本口径在收集评分前确定，适用于 50 个源图、每源三个默认输出（生成 seed 0）。三份 ZIP、作答题目和逐源解释沿用原分发。评分者只收到自己的一份 ZIP，独立判断指定对象上是否出现请求的可见变化。水獭心形变色、女孩与房屋前后关系两题均按问卷列出的模型提示对评分。

## 填写与运行

1. 分发前记下本轮参加的两位或三位评分者编号。评分者在解压后的 `index.html` 逐题填 1 或 0，可另勾疑虑，也可跳过。协调者按原样保存每人一份最终导出和原始分配密钥。
2. 在本目录运行下列命令。文件名和编号填实际分配者；三人时同时补上第三份文件和编号。`--raters` 检查回收集合是否与登记一致。缺整份导出时，报告回收进度，待登记组到齐再作正式汇总。单份导出仍可按原命令查看作答进度。

```text
python organizer/score.py R01-ratings.json R02-ratings.json --raters R01 R02 --out summary.json
```

## 预先确定的统计量

- **共同分母。** 记登记评分者数为 R。一张源图只有在 R 人均评完其 Uniform、Two constants、Spatial 三项时才进入主分析。三臂及三项差值始终使用同一组 n 张源图。跳过为缺失，任一缺票即整源退出主分析；疑虑标记保留原票。逐人作答、缺失及疑虑数另列。
- **成功率与分歧。** 对每个源、每个配置先取 R 张二元票的平均，再对 n 个源等权平均。报告成功票数 / (n × R)、成功率和区间。两人一票成功、一票失败时该源记 0.5，三人有分歧时记 1/3 或 2/3。保留原票，并列出全票成功、全票失败和分票的源数。
- **同源差值。** 按 Spatial − Uniform、Spatial − Two constants、Two constants − Uniform 三个方向，用每张源图两臂的平均分之差，再对源取均值。正值表示前一臂成功率较高；两臂同票的源以零差进入均值。JSON 用比例，写作时差值和区间端点同乘 100，单位为百分点。
- **95% 区间。** 用排序后的源 ID 建立抽样顺序，以 Python 标准库 `random.Random(0)` 等概率有放回抽 n 个源，重复 10,000 次。每次整组携带同源的三臂和全部评分者，共用该次抽样计算所有率和差。取 2.5%、97.5% 分位数，在排序后 (B−1)p 处线性插值。区间反映固定评分者下的源间抽样变异，各项单独覆盖。n=0 时无估计；n=1 时有点估计，区间为 `null`。全体源差相同时区间可退化为一点。
- **一致性。** 单位为“源 × 配置”。两人用二元未加权 Cohen’s κ；三人用 Fleiss’ κ，另列三组两两 Cohen’s κ。同时给直接一致率和共同已评项目数，整体和分臂各报。Cohen 用该两人的项目交集，Fleiss 用三人交集，因此一致性分母可大于主分析对应的完整项目数。三人直接一致率指项目内评分者对的一致比例。无共同项目或机会一致率为 1 时，κ 为 `null`。

## 结果回填位置

| 位置 | 从真实 `summary.json` 取值 |
|---|---|
| 正文 “Interpreting a matched score” 段 | `paired_sources.complete_sources` / 50、评分者数、`paired_sources.by_arm` 三臂成功率及 `ci95`、`paired_sources.contrasts` 中 Spatial − Uniform 的百分点差及区间。说明评分针对默认设置。 |
| 补充材料 “Scope of the paired evidence” | 列出共同分母上三臂的成功票数/总票数、分票源数、全部三项配对差及区间、优/平/劣源数。用顶层 `by_arm.<arm>.per_rater` 报逐人覆盖与疑虑数，用 `paired_sources.excluded_source_ids` 核对漏评。 |
| 补充材料一致性与复现 | 从 `pooled_agreement_and_coverage.cohen`（两人）或 `.fleiss`（三人）取 κ、直接一致率和项目数。各臂同类字段在顶层 `by_arm.<arm>`。保留各人原始导出、密钥和本次命令；`paired_sources.source_yes_votes` 可复算共同源上的率和差。 |

配置键为 `sam_native`（Spatial）、`uniform`（Uniform）、`two_constant`（Two constants）。顶层 `by_arm` 保留原接口、按各臂可用项目汇总；正文的三臂可比数字统一取 `paired_sources`。
