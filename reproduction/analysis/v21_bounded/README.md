# Bounded SAM matched-response sensitivity

Run `python -B analysis/v21_bounded/bounded_mrc.py` from a revision checkout or an extracted anonymous review supplement with the script in this relative location. Alternatively, run `python -B bounded_mrc.py --records A_ICME_Review_Supplement.zip --output rerun` from the directory containing the script, with the ZIP path relative to the current directory or absolute. Only Python 3 and NumPy are needed. Integrators can copy this directory into the packet without duplicating any inputs.

The portable script joins `SAM_scan/data/scores.csv` to `cpu/harmonized_lpips/sam_core_scores.csv` and `cpu/harmonized_lpips/sam_scan_scores.csv` by job ID, checking case, seed, method, background eligibility and grid completeness. In the research checkout it reads the corresponding files under `analysis/metrics/` and `analysis/harmonized_lpips/`. The earlier scan-only packet contains the masked-input outcome but lacks the harmonized feature-map scores; use the review supplement for both outcomes.

## Design and estimands

The full grid was specified before scan scoring. The four-setting bound is post hoc. S is the native spatial SAM allocation, U is the uniform allocation. The two grids have matching scales on the two arms: full = 0.25, 0.50, 0.75, 1.00, 1.25; bounded = the first four settings. The default comparison is always U minus S at scale 1.00. The native spatial mask and the uniform unit map have weights in [0,1] before scaling. Removing scale 1.25 bounds the two arms' projection coefficients by one. As an additional archive check, the model and visible factors on all 26 logged steps were inspected for all 500 S/U runs. All 400 lower-scale runs had effective factors in [0,1]; at 1.25 every S and U run reached 1.25 on both branches. Spatial factors are the logged model/visible factor extrema; the applied uniform factors are the logged model/visible gains.

Per source, intersect the arms' *directional CLIP* ranges. Require complete measured points on both arms and a strictly positive width. Connect consecutive points in ascending scale order. At each response follow the first segment reaching it. A zero-span segment contributes zero area; a tie uses its first endpoint. Split at measured response knots, sum the midpoint signed differences times the subinterval widths, and divide by total width. Signed MRC and default preservation differences are U minus S (positive favors S). Each source with a supported curve has one vote. The retained fraction is the mean matched difference divided by the mean scale-1 default difference on exactly the same supported source IDs. Per-image ratios are never averaged. For each comparison resample paired sources 10,000 times, NumPy default RNG seed 0 and ascending source IDs; recompute both means and their ratio for each draw. Intervals are marginal 2.5th and 97.5th percentiles. All resampled default denominators remained positive.

`spatial` is background-area-averaged full-image AlexNet-v0.1 LPIPS. `black` blacks out the edit region before feature extraction and uses the scalar full-frame LPIPS score. Both use the same 42 background-eligible sources of 50. Source-level support is determined by CLIP alone and is common to both scorers.

## Outputs

- `summary.csv`: each scorer under full, bounded, full grid on the bounded grid's supported source IDs, and full grid on those IDs **and** the bounded intervals. Includes fixed-default and matched CIs, matched-minus-default CIs, retained-ratio CIs, median width, exclusion and sign counts.
- `per_source.csv`: all 50 public IDs for every group and scorer. For a disjoint interval the lower candidate bound exceeds the upper candidate bound. An excluded common-source row can retain its full-grid bounds for inspection; its matched value is blank.
- `common_set_change.csv`: bounded minus full on the 40 overlapping IDs, with paired differences in LPIPS and retained fraction (multiply the latter by 100 for percentage points), sign swaps, and per-source equality audit on identical intervals.

The full grid has one disjoint eligible source, 712000000004. The bounded grid also loses jar 513000000001: the candidate lower bound is 0.04837019, the upper 0.02631953. There are no missing points or touching ranges. The 40-source feature-map sign swaps are 114000000004 (negative to positive) and 523000000003 (positive to negative). With masked inputs, 714000000000 also goes from positive to negative. On fixed bounded response intervals, the additional terminal segment can never precede the original segments, so the first-crossing predictions coincide.

The full-grid source estimates agree with the frozen feature-map and masked-input MRC records, and a run directly against the anonymous review ZIP reproduced the three checkout output CSVs byte for byte.

## Thinning within the bounded grid

Run `python -B analysis/v21_bounded/bounded_thinning.py` from the checkout, or run `python -B bounded_thinning.py --records A_ICME_Review_Supplement.zip --output rerun` with `bounded_mrc.py` beside the entry point. It uses the same recorded inputs, first-crossing integrator, source bootstrap and retained-fraction convention as the preceding analysis. The separate earlier five-to-three comparison uses scales 0.25, 0.75 and **1.25**. All grids below end at **1.00**; this is a post hoc spacing sensitivity confined to the bounded coefficient range.

The four-setting reference uses 0.25, 0.50, 0.75 and 1.00. Both arms retain identical settings. `keep_050` drops 0.75; `keep_075` drops 0.50. For every retained fraction the denominator is the mean U minus S at scale 1 on exactly the source IDs contributing its matched numerator. Every delta in the paired CSV evaluates three minus four on the same IDs, in the same bootstrap draws. The four-setting group mean over all 40 supported sources serves as a descriptive baseline; the paired comparisons use the corresponding 38 or 39 sources. A second analysis fixes the population at the 37 sources supported by all three grids.

- `thinning_sources.csv` contains all 50 source IDs per grid and scorer, status, individual support, default, matched difference, and four-setting MRC on its original and restricted intervals.
- `thinning_summary.csv` gives group means, 95% percentile bootstrap intervals, sign counts and retained fractions. `grid_support` uses each grid's own observed support and `common_sources` fixes the population to the shared 37 IDs. All three default denominators in the shared-source rows agree within each scorer.
- `thinning_paired.csv` gives thin-minus-four differences on paired IDs. Columns beginning `own_intervals` use each grid's native overlap. Columns beginning `identical_interval` evaluate both curves on that source's thinned interval. Retained-fraction differences are fractions (multiply by 100 for percentage points). LPIPS signs and sign flips are relative to the four-setting curves on their own intervals.

With feature-map LPIPS, the four-setting grid has 37 positive and 3 negative differences. Keeping 0.50 yields 37 positive and 1 negative, loses support on 624000000003 and 824000000007, and changes the sign of 511000000000. Keeping 0.75 yields 37 positive and 2 negative, loses 523000000003, and preserves every remaining sign. No supported differences are zero. Masked-input outcomes are recorded in the same output tables.
